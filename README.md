# sgapp 배포

sgapp(지인용 TRPG 채팅 앱)의 **설치 파일 배포 전용** 저장소예요. 소스 코드는 여기 없어요.

초대코드가 있어야 가입할 수 있어요. 초대코드는 관리자에게 받으세요.

## 내려받기

[최신 릴리스](https://github.com/hrpark116-dotcom/sgapp-releases/releases/latest)에서 기기에 맞는 파일을 받으세요.

| 기기 | 파일 |
|---|---|
| Windows PC | `sgapp-Setup-<버전>.exe` |
| 안드로이드 | `sgapp-<버전>.apk` |

## 설치

### Windows PC
1. `sgapp-Setup-<버전>.exe`를 실행하세요.
2. "Windows의 PC 보호" 창이 뜨면 **추가 정보 → 실행**을 누르세요. 서명하지 않은 개인 배포 앱이라 처음 한 번 뜰 수 있어요.
3. 설치가 끝나면 트레이(작업 표시줄 오른쪽 아래)에 상주해요. 새 버전은 앱이 알아서 받아 두고, 설정 탭에서 재시작하면 적용돼요.

### 안드로이드
1. 폰에서 `sgapp-<버전>.apk`를 받아 여세요.
2. "출처를 알 수 없는 앱" 설치를 허용하라는 안내가 나오면 허용하세요.
3. 처음 실행할 때 알림 권한을 허용하고, 안내에 따라 배터리 최적화 예외를 설정하면 알림이 늦게 오지 않아요.
4. 새 버전이 나오면 앱의 설정 탭에서 업데이트를 받을 수 있어요.

## 문의
설치나 사용 중 문제는 관리자에게 알려주세요.
